# Registro de Cambios (Changelog)
Todas las modificaciones notables de este proyecto están documentadas en este archivo siguiendo el formato [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y versionado semántico [SemVer](https://semver.org/).

## [1.1.0] - 2026-08-31
### Añadido
- Integración de los 4 artículos oficiales de investigación científica de la competencia **DataJam de la Alcaldía Mayor de Bogotá** con DOIs, resúmenes formales y badges metodológicos.
- Función reactiva `copyBibtex(paperId)` para la generación y copiado instantáneo de citas académicas BibTeX.
- Visor interactivo de 5 etapas para la plataforma territorial **SIPTA (Data Olinguitos Gen)** con simulador de consola en vivo.
- Espacio abierto de coinvestigación cuantitativa para colaboración académica.

### Modificado
- Actualización formal del perfil académico en todos los archivos a: **Estudiante de Ingeniería de Software y Ciencia de Datos** (Universidad de La Salle) · **Programador Junior Certificado**.
- Corrección y verificación del correo profesional oficial: `adansanchez@hotmail.com`.
- Refactorización de la matriz de habilidades con porcentajes calibrados (Python 96%, Java 94%, R 88%, SciPy 92%, Scikit-Learn 90%).

### Eliminado
- Tabla genérica de pruebas de hipótesis preliminares para dar paso al catálogo estructurado de artículos científicos.

## [1.0.0] - 2026-08-31
