# ADR-001: Adopción de Vanilla CSS & JavaScript ES6+ Nativo
**Fecha**: 2026-08-31  
**Estado**: Aceptado  
**Fase PDCO**: DEVELOPMENT  

## Contexto
El portafolio debe proyectar excelencia técnica, máxima velocidad de carga (FCP $< 0.8\text{s}$), independencia de dependencias frágiles que queden obsoletas y facilidad de despliegue en GitHub Pages sin pasos complejos de transpilación o empaquetado.

## Decisión
Se decide prescindir de frameworks pesados (React, Next.js, Angular) y librerías utilitarias (Tailwind) en favor de:
1. **HTML5 Semántico**: Para accesibilidad nativa y SEO estructurado.
2. **Vanilla CSS3 con Custom Properties (CSS Tokens)**: Para control absoluto de efectos visuales (Dark Glassmorphism, animaciones GPU).
3. **JavaScript ES6+**: Para manipulación reactiva del DOM basada en eventos.

## Consecuencias
**Positivas**:
- Cero dependencias en `node_modules`.
- Carga ultra rápida sin latencia de JavaScript hydration.
- Portabilidad inmediata en cualquier servidor web estático.

**Negativas / Trade-offs**:
- Manejo manual de eventos y componentes en lugar de JSX declarativo (mitigado con funciones modulares bien estructuradas).
