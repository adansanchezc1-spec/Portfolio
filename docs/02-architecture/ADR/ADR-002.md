# ADR-002: Enlace Dinámico de Proyectos hacia Repositorios Públicos GitHub
**Fecha**: 2026-08-31  
**Estado**: Aceptado  
**Fase PDCO**: DEVELOPMENT  

## Contexto
El portafolio debe validar la autenticidad y excelencia del código fuente de proyectos de Data Science, Machine Learning y Software Enterprise ante reclutadores y evaluadores técnicos.

## Decisión
Se establece un sistema de enlace directo y transparente a repositorios oficiales de GitHub (`adansanchezc1-spec`) para cada proyecto:
- *SIPTA — DataJam Alcaldía de Bogotá*: [DataJam_DataOlinguitos_Gen](https://github.com/adansanchezc1-spec/DataJam_DataOlinguitos_Gen)
- *Machine Learning Telecom — CGI U. Tokio*: [TelecomDemand_Prediction_UTokyo](https://github.com/adansanchezc1-spec/TelecomDemand_Prediction_UTokyo)
- *Pipeline Data Wrangling Bogotá*: [ProyectoDataWrangling](https://github.com/adansanchezc1-spec/ProyectoDataWrangling)
- *Power BI Analytics Solutions*: [PowerBI_Analytics_Solutions](https://github.com/adansanchezc1-spec/PowerBI_Analytics_Solutions)

## Consecuencias
**Positivas**:
- Verificabilidad 100% auditable del código, pruebas unitarias y documentación técnica.
- Protección contra restricciones de políticas de seguridad iFrame (clickjacking).
